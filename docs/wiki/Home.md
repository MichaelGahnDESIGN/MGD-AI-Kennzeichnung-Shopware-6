# MGD AI Kennzeichnung Shopware 6

Willkommen im vollständigen Handbuch für **MGD AI Kennzeichnung Shopware 6**. Das Plugin hilft Shops, KI-generierte und KI-bearbeitete Bilder transparent, übersetzbar und barrierearm zu kennzeichnen. Die Entscheidung über den richtigen Status trifft immer ein verantwortlicher Mensch.

Das Plugin analysiert keine Bilder, überträgt keine Medien an externe Dienste und ersetzt keine rechtliche Prüfung. Es ergänzt Shopwares Medienverwaltung und Storefront-Ausgabe um einen kontrollierten Kennzeichnungsweg.

## Schnellstart

1. Vor der Installation ein Backup anlegen.
2. Das aktuelle Paket von der [Release-Seite](https://github.com/MichaelGahnDESIGN/MGD-AI-Kennzeichnung-Shopware-6/releases/latest) herunterladen.
3. In Shopware hochladen, installieren und aktivieren.
4. Cache leeren und Theme kompilieren.
5. In **Inhalte → Medien** ein Bild öffnen.
6. KI-Status, Position und Theme wählen und speichern.
7. Die Ausgabe im echten Verkaufskanal kontrollieren.
